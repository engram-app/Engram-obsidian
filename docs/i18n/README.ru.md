## Что вы получаете

- **Ваш ИИ работает *внутри* хранилища.** Подключите Claude, Cursor или ChatGPT по [MCP](#подключите-свой-ии). Он читает ваши заметки как контекст и записывает новые:
- **Ваши заметки на каждом устройстве.** Пишете на ноутбуке, и это уже на телефоне, а правки, сделанные ИИ, тоже приходят.
- **Находите что угодно, по смыслу или по точному слову.** Нажмите значок поиска и выберите режим: *смысловой* ведёт от *«наша политика возвратов»* к **«Справочник поддержки клиентов»**, даже если в заметке ни разу нет слова «политика». *По ключевым словам* совпадает точно и локально (работает без сети и не расходует квоту). *Смешанный* объединяет оба.
- **Хранилище программируемо.** Полный [REST и WebSocket API](https://engram.page/docs/api) охватывает каждую заметку: автоматизируйте, встраивайте или создавайте приложения на основе собственных знаний.

```text
Вы       Собери то, что мы знаем по клиенту Henderson.

Claude   🔎  хранилище просмотрено ·  найдено 4 заметки
         Сейчас идёт продление, во втором квартале отмечали
         пробелы при внедрении, и спрашивали про модуль аналитики.

Вы       Сделай заметку с упором на риски продления.

Claude   📝  создана «Henderson: риски продления»  ✓
         Связана с четырьмя исходными заметками.
```

Ничто никогда не затирается молча. Правки, сделанные без сети, синхронизируются при подключении. Ваши заметки уходят только в Engram, никогда третьей стороне, и никакой слежки нет.

## Установка

**1. Получите учётную запись Engram.** Размещённый сервис на **[engram.page](https://engram.page)** (бесплатный уровень, ничего устанавливать не нужно) либо разместите [бэкенд с доступным исходным кодом](https://github.com/engram-app/engram) у себя, чтобы заметки никогда не покидали ваше оборудование.

**2. Подключитесь.** Откройте *Settings → Engram Vault Sync*. **Размещённый сервис:** нажмите **Sign in** на вкладке Cloud. **Своё размещение:** укажите адрес сервера и ключ на вкладке Self-hosted. В обоих случаях плагин проведёт вас через первую синхронизацию; до вашего подтверждения ничего не отправляется.

Дальше синхронизация идёт сама, пока вы работаете.

**Хотите посмотреть?** [Видео об установке](https://www.youtube.com/watch?v=rwnPeZ-8Lqo) показывает оба шага целиком.

## Подключите свой ИИ

Engram говорит на **MCP (Model Context Protocol)**, открытом стандарте, через который Claude, Cursor, ChatGPT и другие приложения обращаются к внешним инструментам. Достаточно подключить один раз, и ИИ сможет искать ваши заметки, писать новые и обновлять существующие прямо в вашем хранилище.

Направьте клиент на MCP-сервер Engram (`https://mcp.engram.page` в размещённом сервисе). Пошаговые руководства для каждого приложения есть в **[документации по интеграциям](https://engram.page/docs/integrations)**.

## Конфиденциальность

- **Сетевые обращения и учётные записи.** Плагин обращается только к вашему серверу Engram, больше никуда, без посредников. Вход выполняется через OAuth в учётную запись Engram и работает на любом тарифе. Ключи API тоже поддерживаются, но в Engram Cloud для них нужен тариф Pro; на своих серверах такого ограничения нет.
- **Никакой телеметрии.** Необязательное удалённое журналирование (по умолчанию выключено) отправляет только события ошибок и жизненного цикла, и только на ваш сервер.
- **Конфиденциальность размещённого сервиса.** См. [engram.page/privacy](https://engram.page/privacy). Платные уровни повышают пределы хранения и поиска; своё размещение бесплатно.
